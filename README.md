# Semana 10 — Biblioteca de barrio

Laboratorio React de componentes, props, estado y eventos. El proyecto se encuentra en [`frontend/`](frontend/README.md), copiado de Semana 9 sin modificar el original.

```sh
cd frontend
npm install
npm run dev
npm run lint
npm run build
```

Consulta el [README del frontend](frontend/README.md) para la lista de componentes, sus props, validaciones y comprobaciones manuales. Los datos son locales, escritos a mano; la conexión con la API corresponde a Semana 12.

Repositorio Git nuevo para Semana 10. `node_modules/` y `dist/` están excluidos mediante `.gitignore`.
